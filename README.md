# Octopus

Octopus adalah konsep browser mobile-first berbahasa Indonesia dengan pencarian cepat, cuaca, navigasi favorit, dan menu alat privasi.

## Fitur saat ini

- Beranda dengan branding Octopus, search bar, kategori Web/Gambar/Video/Berita/Populer, dan kartu cuaca.
- Navigasi bawah untuk Beranda, Tab, Favorit, dan Alat.
- Menu alat dengan VPN, tab pribadi, pemblokir iklan, riwayat, unduhan, favorit, mode gelap, situs desktop, hemat data, pengaturan, dan bahasa.
- Toggle interaktif dan notifikasi ringan untuk fitur yang belum terhubung ke backend.
- Responsive mobile-first dengan tampilan desktop berbentuk device frame.

## Menjalankan secara lokal

```bash
pnpm install
pnpm dev
```

Untuk production build:

```bash
pnpm check
pnpm build
```

## Stack

React 19, TypeScript, Vite, Tailwind CSS, dan lucide-react.
